# hossein-mods

A Claude Code plugin marketplace.

| Plugin | What it does |
| --- | --- |
| [session-usage-band](plugins/session-usage-band/README.md) | A calm band above the prompt: prompt-cache countdown, cost, tokens, context and 5h/7d limits. |

```bash
claude plugin marketplace add /path/to/claude-mod
claude plugin install session-usage-band@hossein-mods
```
